# duartemarqs.github.io

Personal portfolio of Duarte Marques — interaction design, data visualization and audio.

Static site (plain HTML/CSS, no build step), hosted for free on GitHub Pages.

- `index.html` — home: projects, music, education, contact
- `projects/` — one case study per project
- `assets/` — stylesheet, images and video
- `cv/` — CV in English and Portuguese (PDF)

To update: edit the HTML files and push to `main`. GitHub Pages republishes automatically.
